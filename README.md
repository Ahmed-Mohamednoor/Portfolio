# Ahmed Mohamednoor — Portfolio

Personal data engineering portfolio built with HTML, CSS, and vanilla JavaScript.

## Preview locally

Open `index.html` in a browser. No build step or dependencies are required.

## Features

- Responsive layout and mobile navigation
- Light and dark themes
- Experience timeline and expandable project details
- Filterable technical skills
- Downloadable CV and contact links
- Keyboard focus indicators and reduced-motion support

## Files

- `index.html` — content and page structure
- `styles.css` — layout, themes, and responsive styling
- `script.js` — navigation, filtering, theme switching, and scroll interactions
- `images/ahmed-portrait.jpeg` — portfolio portrait
- `Ahmed_Mohamednoor_CV.pdf` — downloadable CV

## Editing

Update the content in `index.html`, adjust the colors in `styles.css`, and replace the CV file when needed.
